# 🧠 Manoveda - AI-Powered Mental Health Assessment & Support System

Welcome to **Manoveda**, a project born from purpose—an AI-driven solution to assess, understand, and support mental well-being through intelligent technology and empathetic design.

## 🌟 Overview

Manoveda was built during [HashHacks 7.0](https://hashhacks.hashhacks.tech) — a 24-hour hackathon organized by the Cluster Innovation Centre, University of Delhi.  
This project aims to use **Artificial Intelligence and Natural Language Processing (NLP)** to detect early signs of **depression or emotional distress** and provide supportive interventions.

## 💡 Features

- 🔍 **Sentiment Analysis Engine**  
  Analyzes user inputs like journal entries or chat responses to detect emotional tone and flag signs of sadness, stress, or anxiety.

- 💬 **AI Chatbot**  
  Offers friendly and empathetic conversations, grounding techniques, and motivational nudges based on the user's sentiment.

- 📈 **Mood Tracker Dashboard**  
  Visualizes emotional trends over time, helping users become more aware of their mental state.

- 🎯 **Smart Suggestions**  
  Personalized coping techniques, self-care tasks, meditative prompts, and helpline links curated by AI.

## ⚙️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript (React / Bootstrap)
- **Backend**: Python (Flask)
- **Machine Learning**: Scikit-learn, NLTK, Vader Sentiment
- **Database**: SQLite / MongoDB
- **Deployment**: Localhost (Planned: Render / Heroku)

## 🧪 AI/ML Workflow

- **Text Preprocessing**: Tokenization, stopword removal
- **Model**: Sentiment analysis using `VADER` and a Logistic Regression classifier trained on labeled mental health datasets
- **Response Engine**: Based on sentiment polarity + keyword context
